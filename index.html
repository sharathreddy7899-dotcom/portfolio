Featured Projects

Prompt-to-Video Generative AI Platform

A full-stack AI-powered video generation platform that transforms detailed natural-language prompts into cinematic short videos with prompt enhancement, AI Director assistance, and downloadable outputs.

This production-grade AI system integrates a transformer-based text processing pipeline with generative AI models to convert rich prompts into visually coherent video outputs. The platform includes a prompt enhancement engine that rewrites user prompts for improved semantic alignment, an AI Director module that suggests camera work and lighting techniques, and a structured orchestration pipeline that manages generation and export.

Frontend is built using React with a clean corporate UI. Backend is implemented using Django REST APIs with authentication, history tracking, and generation management. MongoDB stores user and project metadata. The system supports multiple visual styles, aspect ratios, video preview, and MP4 download functionality.

Key Features

  • Prompt enhancement engine
  • AI Director suggestions (camera + lighting)
  • Multiple visual styles (Realistic, Animated, Cartoon, Anime)
  • Aspect ratio selection (16:9, 9:16, 1:1)
  • User authentication system
  • Video history dashboard
  • MP4 export and preview

Automatic Rain Detector & Clothes Collection System

An IoT-based smart home automation prototype that detects rain and automatically retracts clothes using sensor-driven motor control with real-time alerts.

This project is a fully functional IoT prototype built using Arduino Uno and an LM393 rain sensor. The system continuously monitors moisture levels and automatically activates a motorized retraction mechanism when rainfall is detected. An LCD display provides system status updates, and a buzzer alerts users during heavy rain conditions.

The physical prototype includes a structured house model demonstrating real-world deployment. The system integrates sensor polling logic, threshold calibration, motor control sequencing, and user feedback mechanisms.

Key Features

  • Real-time rain detection
  • Adjustable moisture threshold
  • Automatic motor retraction
  • LCD status display
  • Audible buzzer alerts
  • Physical working prototype

My Role & Contribution

I built the complete hardware and software system as Team Lead. I wrote the Arduino firmware, designed and wired the circuit, implemented motor control and safety logic, integrated LCD and buzzer components, constructed the physical prototype, and conducted calibration and testing. I also prepared documentation and led the project presentation.
