RESUME FOLDER
=============

Upload your resume PDF file here with the name: Sharath_GA_Resume.pdf

The website is configured to open this file when users click the "Resume" button.

Instructions:
1. Save your resume as: Sharath_GA_Resume.pdf
2. Place it in this folder (portfolio/resume/)
3. The Resume button will automatically work

Alternative names you can use:
- Sharath_GA_Resume.pdf (recommended)
- resume.pdf
- Sharath_Resume.pdf

If you use a different name, update the file path in script.js:
Line: window.open('resume/YOUR_FILE_NAME.pdf', '_blank');
